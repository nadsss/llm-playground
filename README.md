# LLM Playground (Week 1 Project 1)

A hands-on playground to explore:
- Tokenization
- GPT-2 generation
- Decoding controls (`temperature`, `top_k`, `top_p`)
- Prompt sensitivity
- Completion vs instruction-style prompts

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
python llm_playground.py
```

## Notes

- Uses `gpt2` from Hugging Face.
- First run downloads model files.
